# Домашнее задание №1: «Анкета»

MAUI-приложение с анкетой на тему дегустации чая.

Для ввода даты был реализован кастомный компонент:
-Entry для ввода с клавиатуры Numeric;
-Button для открытия календаря;
-DatePicker в роли календаря.

Для ввода даты в Entry нужно вводить только цифры, точки подставятся сами.
Логика поля не защищена от неправильного использования (например, удаления точек), но валидация в любом случае пропускает только корректные даты.
